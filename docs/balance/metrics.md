# バランス測定指標

## 基本原則

- 現行実装の事実と、目標とする値を分けて記録する。
- 平均値だけで合否を決めない。
- 同じ初期状態、プレイヤーモデル、乱数種で変更前後を比較する。
- 通常進行、単発襲撃、襲撃後復旧、黙示録を別の試行として測る。
- モーダル未処理や例外停止を、ゲーム内の敗北として数えない。測定エラーとして分離する。

## ゲームオーバー

現行実装がゲームオーバーと判定した状態を、そのままゲームオーバーとして数えます。現在の概要上は、村人が0人になることが中心条件です。

将来、ゲームオーバー条件が追加された場合は、保存互換性と月次処理を確認したうえでこの定義を更新します。

## 安定状態

危機から立て直したと判定するには、期限時点で次をすべて満たす必要があります。

- 負傷・重体ではなく、通常の仕事に就ける成人村人が4人以上いる。
- 現在人口が仕事をしなくても約3か月生存できる食料がある。
- 画面が算出する次の冬越しに必要な資材目標を満たしている。
- 重体者が0人である。
- 通常の負傷者は残っていてもよい。ただし、上記の労働力と備蓄を維持したまま療養できることを要する。

通常襲撃の専用復旧指標では、これより厳しいHP・メンタル条件を使う場合があります。

## 実質的な詰み

ゲームオーバーではないが、通常のプレイで立て直せる可能性が極端に低い状態を実質的な詰みと呼びます。

判定手順は次のとおりです。

1. 危機状態のスナップショットを保存する。
2. その状態から熟練者の立て直し方針へ切り替える。
3. 異なる乱数種で100回、12か月継続する。
4. 12か月以内に安定状態へ戻った回数を数える。
5. 安定復帰が10回未満なら、元の状態を実質的な詰みと判定する。

10回以上復帰できても深刻な危機である場合は、復帰率をそのまま報告し、詰み以外の危険度区分を測定後に検討します。

## 累積詰み率

ゲーム開始から指定時点までに、ゲームオーバーまたは実質的な詰みに到達した試行の割合です。一度詰みと判定した試行は、その後の偶然の救済を待たず累積値へ数えます。

暫定目標は次のとおりです。

| プレイヤー | 1年 | 2年 | 3年 |
| --- | ---: | ---: | ---: |
| 初心者 | 15%以下 | 25%以下 | 35%以下 |
| 標準 | 8%以下 | 14%以下 | 20%以下 |
| 熟練者 | 2%以下 | 4%以下 | 5%以下 |

3年値を主要目標とし、1年値と2年値は難易度が特定期間へ偏っていないかを判断する補助目標とします。

## 判断が不要になった状態

安定した村が、プレイヤーの再判断なしに長期間安全である状態をヌルゲー化候補として測ります。

判定手順は次のとおりです。

1. ある時点の仕事割当と防衛編成を固定する。
2. 奇跡を使用せず、手動の再割当や再編成もせずに進める。
3. 異なる乱数種で100回、12か月継続する。
4. 90回以上が期間中ずっと安定条件を維持した場合、判断が不要になった状態の候補とする。

標準プレイヤー1,000試行の3年終了時点で、この候補に該当する村を20%以下にすることを暫定目標とします。

これは安全な村そのものを否定する指標ではありません。建築、勧誘、季節対応などの判断を止めてもほぼ結果が変わらない状態を検出するために使います。

## 発展速度

標準プレイヤーの村規模中央値について、次を観測目安とします。

| 経過 | 規模中央値の目安 |
| --- | ---: |
| 1年 | 30 |
| 2年 | 70 |
| 3年 | 120 |

この表だけで合否を決めません。各時点の人口、食料月数、冬支度、建物、負傷者、襲撃履歴も併記します。

## 襲撃結果

襲撃結果は、完全成功と部分成功を合算した「成功」と、失敗で合否を判断します。診断用には完全成功、部分成功、失敗を別々にも記録しますが、完全成功と部分成功の比率自体は目標にしません。結果名称だけでなく、敵残数、味方負傷、重体、死亡、HP、メンタル、建物損壊、資源損失を記録します。

準備済み村の暫定目標は次のとおりです。

| 襲撃段階 | 成功率目標 | 大量試行時の失敗率上限 |
| --- | ---: | ---: |
| 下位 | 99%以上 | 1% |
| 中位 | 98%以上 | 2% |
| 上位 | 99%以上 | 1% |

成功は完全成功と部分成功の合計です。上位襲撃では失敗率1%以下を優先し、完全成功と部分成功の内訳は問いません。

発展が多少遅れた村は、完全成功と部分成功の合計60%以上を目標にします。

## 負傷と復旧

通常襲撃の復旧期間は、結果確定後から所定の復旧条件を初めて満たすまでの月数です。

- 下位襲撃: 平均2か月以内。
- 中位襲撃: 平均3か月以内。
- 上位襲撃: 平均4か月以内。

上位襲撃の専用試行では、負傷者0人かつ全村人のHP・メンタルが80以上になった月を復旧とします。完全成功と部分成功を合わせた成功群で平均4か月以内を目標にします。成功群の平均負傷者数は4人以下を目標にします。

通常襲撃で1回敗北した村は、標準的な立て直しにより12か月以内に80%以上が安定状態へ戻ることを目標にします。連続敗北には同じ保証を置きません。

## 黄金像の建立時期

ゲーム開始から、黄金像を建築し、かつ黙示録用の戦力・設備・備蓄条件を満たした時点までの月数を測ります。

- 中央値: 9年。
- 標準目標: 8～10年。
- 許容範囲: 6～12年。
- 6年未満と12年超の割合を別に報告する。
- イベント解放待ち、規模到達、神威到達、人口到達、備蓄到達を分解して記録する。

## 黙示録

黙示録は第1段階から仮エンディングまでを1試行とし、中断または第6・第7段階の敗北を未完走として数えます。

暫定目標は次のとおりです。

- 熟練者が全資源を適切に使う: 完走率約80%。
- 奇跡と秘宝を使わない: 完走率0～20%。
- 公開情報だけを知る初見プレイヤー: 完走率30～50%。
- 熟練者が第6段階へ到達する割合: 90%以上。
- 第6・第7段階: 敵全滅のみ成功。部分成功なし。

完走率に加え、各段階到達率、各段階の資源消費、奇跡使用回数、村人損失、建物損壊、終了時備蓄を報告します。

## 試行数と統計

- 通常の基準測定: 条件ごとに1,000回。
- 閾値付近または変更前後の最終比較: 条件ごとに10,000回。
- 実質的な詰みと放置安定の継続判定: スナップショットごとに100回。
- 変更前後は同じ乱数種集合を使用する。
- 平均、中央値、下位10%、下位1%、最小、最大を可能な範囲で報告する。
- 二値結果には信頼区間を付ける。
- 平均復旧期間は通常襲撃の成功群と失敗群を混ぜない。完全成功と部分成功は成功群として合算する。

試行失敗、例外、モーダル停止、タイムアウトは分母へ混ぜず、測定基盤のエラー率として別に報告します。
