## 1. ひとことで言うと

**このゲームは「村を育てる話」の顔をした「身体を配り直す話」であり、その正体はルールの設計そのものに書かれている。**

根拠は一点で足りる。神威Lv0、つまりゲーム開始直後から使える6つの奇跡のなかに、**交換の奇跡（魔素20）がある**（`js/divineMight.js` の `DIVINE_MIGHT_LEVELS`、`js/miracles.js` の id:"12"）。回復も、食料生成も、勧誘も同じ棚に並んでいるが、その棚のいちばん安い品が「2人の肉体を交換する」なのだ。豊穣の奇跡は100、常春は300、稀人は300。人間の身体を丸ごと入れ替える行為が、食料+80のマナの奇跡（40）の**半額**で買える。

これは調整ミスではなく宣言だと読む。この村で最も安く、最も日常的な神の介入は、身体の付け替えである。プレイヤーはチュートリアルを抜ける前に、それを実行できてしまう。

以降は、この一点がゲーム全体にどう反響しているかを追う。

## 2. 遊びの核 — 毎月、プレイヤーは何をしているのか

### 実際の手触り

月次ループは単純だ。行動を割り振り、必要なら建築・奇跡・勧誘を挟み、「次の月へ」を押す。すると行動フェーズ結果モーダル、固定イベント、ランダムイベント、妊娠・出産、襲撃判定が順に流れてくる（`js/events.js` の `doMonthStartProcess` / `endOfMonthProcess`）。

村人が0人になるとゲームオーバー。それ以外に明示的な敗北条件はない。

**評価: 判断の密度は、実は月ごとにかなり薄い。** そしてそれは、この作品の場合、必ずしも欠点になっていない。

理由は、**出来事の量は多いのに、決断を要する出来事がほとんどないから**だ。ここは数えてみると印象が変わる。

ランダムイベントは月1回、行動フェーズ前にのみ判定される（`js/events.js:327` の `doRandomEventPre`。「後」フェーズは廃止済み）。そして判定には `chanceMultiplier: 1.6` がかかっている。素の表（`EVENT_KIND_TABLE`）は神秘1・良25・悪40だが、1.6倍された実効値はこうなる。

| 種別 | 実効確率 |
| --- | ---: |
| 神秘 | 1.6% |
| 良 | 38.4% |
| 悪 | 24.0% |
| 何も起きない | 36.0% |

**つまり月の約2/3で何かが起きている。イベントは十分に頻繁だ。** 問題は中身のほうにある。

`js/RandomEvents.js` の `doGoodEvent` を読むと、良イベント15種のうちプレイヤーに選択肢を出すのは**「狼の子供」1種だけ**（村で飼うか、森に返すか）。残りは全部、結果が自動適用されてログが1行出るだけだ。

```
金貨発見:資金+50〜100
空から魚が降り注いだ:食料+10〜60
花火師来訪:村全体幸福+5〜10
秘湯発見:全員体力+10,公衆浴場建設解放
子猫イベント:◯◯幸福+20〜30
```

しかも一部は条件を満たさないと `return null` で沈黙する（`bathPerk` は公衆浴場と該当人物が必要、`wolfChild` は既に狼がいると発生しない）。空振り分を足せば、体感の「何も起きない月」は36%より確実に多い。

そこへ、決断を要求する出来事のほうを重ねる。

- 通常襲撃は、予約リセット後の期待間隔が約5.4か月、年約2.2回（`docs/balance/baseline-results.md`）。
- 願望（`WISH_START_CHANCE = 0.2`）は礼拝堂建設後にしか発生せず、しかも**村全体で同時に1件だけ**（`village.wish` は単数フィールド）。
- 異端審問・黄金像は、条件を満たした月に25%。

**結論として、平時の月は「無」ではなく「賑やかだが、押すボタンが1つしかない」。** 資金が増え、誰かが幸福になり、猫が来る。プレイヤーはそれを読み、次の月へ進む。判断が発生するのは襲撃予約通知、冬支度資材の不足警告、疫病の感染予約、誰かの願望のときだけだ。

**解釈: この作品の緊張は「毎月の最適化」ではなく「警告欄を読む数秒」に凝縮されている。** 村情報欄の警告表示が、実質的なゲーム画面である。チュートリアルが「警告欄の通常警告の下に1件ずつ」表示される設計（`PROJECT_OVERVIEW.md`）は、その自覚の表れだと思う。プレイヤーに最初に教えているのは操作ではなく、**どこを見て不安になればいいか**だ。

### サボり判定という小さな悪意

好きな仕様がある。行動フェーズの冒頭で、村人ごとに `saboProb = 40 - 勤勉 × 2` % の確率で「サボり」判定が入る（`js/jobs.js` の `handleAllVillagerJobs`）。サボった村人は仕事をせず、体力+20・メンタル+20を得る。精神特性「ニート」持ちなら+40・+40・幸福+20だ。

勤勉20の村人はサボらない。勤勉10なら20%サボる。勤勉5なら30%。

**これがうまい。** 数値としては単なる出力分散だが、ログに「◯◯サボり:体力+20,メンタル+20」と本人の名前で出る。プレイヤーは月末の集計ではなく、**特定の村人の名前を見て舌打ちする**。勤勉が低い村人を雇うか外すかという判断が、効率の話ではなく人物評の話にすり替わる瞬間だ。

しかも「ニート」はサボりが**得**になる。この村では怠惰が明確に報われるルートが1本だけ通っている。豊穣と混沌の神を主人公に置く作品として、これは筋が通っている。

### 自動割り振りの正直さ

`docs/balance/baseline-results.md` に、なかなか残酷な観測が記録されている。建築も襲撃もせず自動割り振りだけで回した10系列で、**神威500に到達した時点の人口が6～7人、10系列中7系列で技術0**。つまり自動割り振りは、村を生かすが、村を育てない。

**評価: これは自動化の失敗ではなく、作品の主張が漏れているところだ。** 生存は自動化できるが、発展は人間が誰を呼び、誰を何にするかを決めないと起きない。村を「回す」ことと村を「大きくする」ことが別物になっている構造は正しい。

ただし後述するように、その差が現状のプレイヤー体験にきちんと突きつけられているかは別問題である。

## 3. 身体と精神が別勘定であること

### 事実としての分離

人物は肉体側と精神側を別に持つ。

- **身体ステータス**: 筋力・耐久・器用・魔力・魅力。肉体交換で肉体とともに移る。
- **精神ステータス**: 知力・勤勉・勇気・倫理・好色。肉体交換をしても精神に残る（`js/data/dictionaryData.js`）。
- 肉体年齢と精神年齢、肉体性別と精神性別が独立。
- 口調は精神側から解決される（`DIALOGUE_RULES.md`、`resolveDialogueTone`）。

そして仕事の可否判定が、この分離をまたぐ。**成人判定は主に精神年齢、性別制限は肉体性別を参照する**（`WORLDVIEW.md`）。

結果として何が起きるか。`WORLDVIEW.md` が自分で書いている。精神が成人したまま赤子の肉体になった人物が、身体を酷使しない詩人・神官・シスターの務めを続けられる。

**評価: これが本作の設計で最も強い一手だ。** 「TSFイベントがある」ゲームなら山ほどある。本作が違うのは、**性別も年齢も種族も、イベントではなく毎月のジョブテーブル計算に入っている**ことだ。あんまは肉体性別で計算式が分岐する（男性肉体は筋力×知力、女性肉体は魅力×好色）。人面獣身の肉体は21種の行動が選択不可になる。飛行は狩猟・採集が1.2倍。

身体は物語の飾りではなく、**労働条件**として扱われている。

### 交換の奇跡がプレイに落ちる形

肉体交換が20マナで撃てるということは、実務的にこうなる。

- 老いて筋力の落ちた村人と、精神年齢が幼いが強靭な肉体の村人を入れ替える。
- 妊娠させたい／させたくない組み合わせを、身体側だけ差し替えて調整する。
- 襲撃者の強い身体を、交換の奇跡・強（100、黄金像があれば50）で奪う。

最後のものが決定的だ。`docs/balance/baseline-results.md` は、翼人兵の交換可能な身体を「筋力12～17.25、耐久16～23、器用15～20.25、魔力18～24、光輪により交換後も魔力+3・魅力+5」と、**装備品のスペック表と同じ書式で**記録している。

**解釈: この作品において敵とは、歩いている装備品である。** 襲撃は「撃退すべき脅威」であると同時に「入荷」だ。しかも収穫祭では毎年、松かさの杖（交換の奇跡・強と同等）が1本無条件で手に入る（`GAME_GUIDE_JA.md`）。**年に一度、村は無料で誰かの身体を持ち替える権利を得る。** それが収穫祭という名前で配られているのが、この作品の性格を最もよく表している。

### 尖った読み — 塩の柱と、赤子の押し付け

ここからは、ルールを組み合わせると立ち上がってしまう戦術の話。ドキュメントが自分で認めている範囲の事実に基づく。

事実:

1. 塩の柱状態は**肉体に属し、肉体交換で相手へ移る**（`Readme.txt` 1.8節）。
2. 肉体交換で襲撃者へ移った塩の柱が戦闘中に1以上のダメージを受けると、**砕け散って体力が0になる**（同上）。
3. 襲撃者が赤子・幼狼・危篤・重体の肉体なら**行動不能かつ被ダメージ3倍**（`Readme.txt` 1.6節）。
4. `docs/balance/design-goals.md` は熟練者の黙示録攻略手段として「塩の柱の押し付け」を**正式に想定戦術として列挙している**。

つまり、黙示録第五の災厄で村人に降った天罰を、松かさの杖で敵に着せ替えて、指一本で砕く。あるいは赤ん坊の身体を敵に押し付けて、無力な肉塊にしてから殴る。

**評価: これは素晴らしく悪趣味で、素晴らしくこのゲームらしい。** 天罰を受け流すのではなく、**天罰を武器として再利用する**。新しき神が村人に刻んだ刑罰が、そのまま新しき神の軍勢を殺す道具になる。神学的な意趣返しとして、これ以上の形はない。

**邪推だが**、作者はここを狙って作ったというより、身体を独立した「もの」として一貫して扱った結果、この戦術が事後的に成立してしまったのだと思う。そして設計目標文書に載せた時点で、作者はそれを見つけて**気に入った**。バランス文書が戦術として容認している事実が、その証拠に見える。歪みを矯正せず、正史に組み込んだのだ。

## 4. 神の手つき — プレイヤーは何をする存在なのか

本作でプレイヤーは村長ではなく、バッカスという神である。この立場が、いくつかの奇跡でかなり露骨に露出する。

### 出立の奇跡（50マナ）

> 1人離脱→幸福度分の魔素獲得

**これがこのゲームで最も薄暗い1行だと思う。** 村人を1人村から出し、**その人物の幸福度と同じ量の魔素**を得る。幸福な村人ほど、多くの神力になる。

数値として見れば、要らない村人の処分と資源回収のコンボにすぎない。だが意味を読めば、**丁寧に育てて幸せにした人間ほど、換金効率がいい**という式だ。宴会の奇跡で全員の幸福+20、噴水で毎月幸福上昇、願望を叶えて幸福上昇——それらの「善政」が、そのまま出立の奇跡の単価を上げている。

**解釈: 神の慈愛と神の収奪が、同じパラメータを共有している。** これを露悪的な演出ではなくコスト計算式として実装したところに、本作の冷たさがある。

### 狂宴の奇跡（人数×30マナ＋同額の資金）

> 全員体力/メンタル+60、幸福+50、失望/絶望解除、倫理↓、好色+15

村人全員の失望と絶望を消し、そのついでに全員の倫理を下げ、好色を+15する。**心の傷を、集団的な酩酊と性欲で上書きする。**

しかも失望・絶望は放置すると離村につながる（`js/events.js` の `leaveVillageByDespair`）。つまりこの奇跡は救済策として実用的だ。プレイヤーは村人を村に留めるために、定期的に彼らを酩酊させ、倫理を削っていく。

**評価: 「豊穣と混沌の神」という設定が、フレーバーではなく治療プロトコルとして実装されている。** バッカスにできる心のケアは、酒と祭りしかない。そしてそれは、実際に効く。副作用込みで。

### 悍ましい肖像画（秘宝）

> 倫理が2以上の村人1名に使用可能。今月のみ精神特性「肖像」を付与し、倫理を1まで下げ、下がった分だけ魅力を上げる。

倫理を魅力に**両替する**。等価交換で。`js/domain/statLayers.js` の `getPortraitEffect` が `{ add: { eth: -ethLoss, chr: ethLoss } }` と書いている、その1行が全部だ。

**邪推: この作品には、徳と色気が同じ通貨で計られているという前提がある。** 好色（sexdr）が精神ステータスとして倫理と同じ棚に並び、誘惑の成功率と妊娠確率の両方に効いている（妊娠確率 = clamp((母好色/30)×(父好色/30)×0.5, 0.05, 0.5)、`js/reproduction.js`）ことも同じ思想だ。清らかさは能力値であり、下ろせる。

## 5. 外圧の構造 — 村が大きくなることの罰

### 三段構えは機能しているか

`WORLDVIEW.md` は脅威を三層に置く。序盤=生存、中盤=目立ちすぎ問題、後半=新しき神との対立。

実装は、これをかなり素直に踏襲している。

- 襲撃テーブルは**村の規模称号で切り替わる**（`RAID_SCALE_TABLES`: early-frontier / frontier-village / mapped-village / rich-village / prosperous-village / autonomous-settlement、さらに異端版2種）。
- 豊かな村以降でゴブリン軍団、自治集落でモンスター・スタンビードが解禁。
- 異端審問は「繁栄した郷村以上・神威Lv3以上」の月初に25%（`GAME_GUIDE_JA.md`）。
- 黄金像は「異端・自治集落・神威Lv5」の月初に25%。

**評価: 「発展が罰として返ってくる」構造は、村運営SLGとしてまっとうに強い。** 規模350の自治集落になるということは、櫓を4基建てられるということであると同時に、**モンスター・スタンビードの襲撃テーブルに載るということ**だ。強くなる報酬と、強くならざるを得なくなる圧力が、同じ数字から出ている。

### 異端審問という分岐

異端審問の選択肢は2つ。資金を払ってもてなすか、追い払うか。追い払うと村特性「異端」が付き、専用襲撃テーブルへ切り替わる（`js/heresyInquisition.js`）。

**この分岐の作りが誠実だ。** もてなす側は「安全だが、バッカスの復権ルートを閉じる」。追い払う側は「黄金像と黙示録という終盤コンテンツへの入場券を買う」。資金不足時はもてなせない、というのも良い。**貧しい村は、選ぶ権利すらないまま異端になる。**

**解釈: プレイヤーが「異端になるか」を選んでいるように見えて、実際には「異端になれるだけの資金があったか」を問われている。** 信仰の選択が経済状況で決まる。中世の辺境村の話としては、これ以上なく皮肉が効いている。

### 黙示録 — 終盤コンテンツとしての評価

七つの災厄（血の川／蝗と飢餓／硫黄／疫病／塩の柱／聖征軍と戦争／翼人兵と支配）は、単なる連戦ではない。

- 第二の災厄「天を覆う蝗」: **食料の60%を喪失**し、3か月間、農作業・採集・伐採・醸造が**0.2倍**。
- 第四: ランダムな村人最大3名が疫病。
- 第五: 勇気が高い側から最大3名が塩の柱（=行動不能）。
- 第六: 7ターン目に《戦争》が出撃中の村人1名へ光の柱。**固定666ダメージ**と、翌月初に危篤になる「曝露」。
- 第六・第七の敗北は黄金像を強制破壊し、黙示録が中断される。

**評価: 構成が良い。** 特に第二と第五が効いている。第二は生産を殺し、第五は**最も勇敢な村人から順に石にする**。つまり黙示録は、戦闘で村を削るのではなく、**戦闘の前提条件を削ってくる**。これは月次経営SLGにおける正しい終盤の圧力のかけ方だ。

第五が「勇気が高い側から」なのも、単なるランダム選出より遥かに残酷でいい。前衛で戦わせるつもりだった村人が、戦う前に塩になる。

そして第六の666ダメージ。**固定値で、しかも防げない。** バランス調整可能なパラメータではなく、宣告として置かれている。良い。

**弱点として: 黙示録は「引き返せる」。** 黄金像を破壊すれば中断でき、解放フラグは残るので再建できる（`GAME_GUIDE_JA.md`）。安全弁としては理解できるが、七つの災厄という題材の重さに対して、**やり直しが軽すぎる**とは思う。天の怒りが、リトライ可能なレイドボスの体裁になってしまっている。ここは後述する。

## 6. 戦闘の実相

### 式を読む

```
迎撃  物理 = floor((筋力 × 勇気 ÷ 400) × 50 − 相手の耐久)
迎撃  魔法 = floor((魔力 × 勇気 ÷ 400) × 25)
射撃      = floor((器用 × 勇気 ÷ 400) × 40 − 相手の耐久 × 1.5)
罠作成    = floor((器用 × 知力 ÷ 400) × 30)   ※0ターン目に1回のみ、以後離脱
```

読みどころが2つある。

**1つ目。魔法攻撃だけ、敵の耐久を引かない。** 係数は50→25と半分だが、高耐久の敵に対しては魔法が唯一通る手段になる。これは装備を持たないゲームにおける、実質的な「属性」の役割を果たしている。

**2つ目。勇気が3つの式すべてに入っている。** 筋力型も、魔力型も、器用型も、勇気がゼロなら何もできない。しかも勇気は**精神ステータス**であり、肉体交換をしても本人に残る。

**解釈: このゲームの戦闘力は、身体ではなく意志に律速されている。** どれだけ立派な翼人兵の身体を奪っても、臆病な村人が着れば火力は出ない。逆に言えば、勇気だけは奇跡でも秘宝でも簡単には買えない——と思いきや、「腕の無い天使像」（全員に勇気+10のニケを1か月）と「戦神の奇跡」（勇気+7、ただし知力・勤勉・倫理×0.2）がある。

戦神の奇跡の副作用が良い。**勇敢にする代わりに、賢さと勤勉さと倫理をほぼ消す。** 火星の加護をかけられた村人は、戦えるが、まともに働けず、まともに考えられない。3か月間。戦争の神が人に何をするかについての、簡潔な意見表明として読める。

### 上位襲撃のバランス評価

`docs/balance/baseline-results.md` の実測（270系列）:

| 襲撃 | 成功率 | 平均負傷者 | 平均ターン |
| --- | ---: | ---: | ---: |
| 聖征騎士団（強） | 99.26% | 2.47 | 2.79 |
| 翼人兵（強） | 100% | 0.43 | 2.69 |

**評価: 「準備した村は負けない」という設計目標は達成されているが、代償として上位襲撃は約2.7ターンで終わる作業になっている。** 特に翼人兵は270戦して0敗、平均負傷者0.43人。これは戦闘ではなく、通行料の徴収である。

しかも診断データが厄介な事実を示している。聖征騎士団の失敗ケースは**すべて迎撃8人と射撃4人が全滅した結果**であり、成功ケースの平均HP0到達者は3.16人。つまり**分布が二極化している**——完勝か、壊滅か。中間の「辛勝」が薄い。

`docs/balance/baseline-results.md` 自身も「敵数だけでは完全成功から味方全滅へ急に移り、部分成功を45～55%へ増やせなかった」と認めている。

**これは式の形の問題だと思う。** ダメージ式が `(能力A × 能力B ÷ 400) × 係数 − 敵耐久` という**引き算**である以上、能力が閾値を超えれば一方的に通り、下回れば一方的に通らない。減算防御は本質的に二極化する。乗算防御（ダメージ × (1 − 軽減率)）に比べて、「ぎりぎり勝った」を作りにくい。

現状の調整は敵の攻撃能力を80%にし「秘蹟：盾」を全員に付ける、という**両側からの詰め方**でこれを吸収している（成功率99.26%）。動いてはいるが、式の性質に逆らって数値を積んでいる状態に見える。

## 7. 言葉の density — セリフデータの物量が何を意味するか

`js/data/dialogue/` 配下だけで約3,700行。用語辞書 `dictionaryData.js` が2,510行。

口調キーは24種類（赤子・男児・女児／普通Ｍ・丁寧Ｍ・強気Ｍ・乱暴・お調子者・陰気・クールＭ／普通Ｆ・丁寧Ｆ・お嬢様・快活・内気・強気Ｆ・蓮っ葉・おっとり・ぶりっこ・クールＦ・ギャル風・中性的／老人・狼・ゴブリン）。

そして願望システムには、**24種すべてに専用の「祈りの型」がある**（`js/data/wishData.js` の `WISH_TONE_PATTERNS`）。同じ願いが、口調ごとに違う祈り方で神へ届く。

```
丁寧Ｆ:  「神さま、お願いがございます。◯◯ どうかお聞き届けください。」
蓮っ葉:  「◯◯ 何とかしてよ。頼んだからね、神さま。」
陰気:    「◯◯ どうせ無理かもしれないけど、頼むよ……。」
クールＭ: 「◯◯ 必要な願いはそれだけだ。」
ゴブリン: 「◯◯ 神さま、頼むゴブ。」
赤子:    「あぅ……うぅ……。（願うように手を伸ばしている）」
狼:      「くぅん……。（祈るように頭を垂れている）」
```

**評価: ここに作者の本体がある。** 13種の願望 × 24口調 × 開始/達成の2フェーズ。誰も全部は見ない。プレイの大半で、プレイヤーが目にするのはこのうち数十パターンだ。それでも書かれている。

そして**赤子と狼は言葉を持たない**。祈れないものが祈っている姿だけが括弧書きで描写される。`DIALOGUE_RULES.md` は赤子について「生後6か月程度の自然さを基準にし、意味のある単語や説明的な発話は避ける」とわざわざ規定している。

**解釈: 本作の一貫性は、システムより先に、この規律にある。** 精神が赤子になった人物には、絶対に賢い台詞を言わせない。TSF・年齢変化を扱う作品が最も安易に堕落するのは、「中身は大人だから普通に喋る」という手抜きだ。本作はそれを規則として禁じている。

代わりに、`exchangeSituationLines.js` という専用ファイルで「入れ替わった身体の年齢・性別・種族・能力と、交換後半年以内の違和感」に応じた通常会話を持っている。**入れ替わった直後の半年だけ、その人物は違和感を口にする。** これは演出として非常に良い。身体は交換した瞬間ではなく、その後の半年で自分のものになる。

### 一方で

ランダムイベントのセリフには、明確な設計上の穴が残っている。`selfPleasure`（自家発電にはまった）、`bathPerk`（役得）、`yuri`（百合の恋）の3つには、コードコメントでこう書かれている。

```js
// イベント条件は精神男性かつ女性肉体。女性口調は通常発生しないため持たせず、矛盾時は男性側fallbackで受ける。
```

**事実として、この3イベントは「精神男性 × 女性肉体」専用である。** つまり本作のTSF要素のうち、快楽・情動に踏み込むイベントは片方向にしか用意されていない。逆（精神女性 × 男性肉体）には対応セリフがない。

**評価: これは作品の趣味の所在が露出している箇所であり、同時に取りこぼしでもある。** `WORLDVIEW.md` は「肉体性別と精神性別のずれ」を中核テーマに掲げ、`DIALOGUE_RULES.md` は「肉体状態・年齢・性別が通常とは異なる組み合わせでも破綻しない文にする」と明記している。にもかかわらず、身体の変化を**楽しむ**セリフだけが一方向に偏っている。

作者の趣味そのものを否定する気はまったくない（むしろ本作の力の源はそこだ）。だが、テーマとして「ずれ」を掲げているなら、逆方向にも同じ密度の反応を置いたほうが、システムの主張とデータの主張が一致する。今は主張がわずかに食い違っている。

## 8. 邪推 — この村は誰のためにあるのか

ここからは根拠のある大胆な読み。作者の意図の断定ではない。

`js/data/wishData.js` の13種の願望を並べてみる。

```
顔も見たくない / モテたい / 近づきたい / 健康になりたい / 強くなりたい /
早くおとなになりたい / 早く一人前になりたい / 子どもに戻りたい /
恋人が欲しい / 若さを取り戻したい / 魔物について調べたい /
希少種族について調べたい / 子どもが欲しい
```

**13個のうち、7個が身体の願いである。** 健康、強さ、成人、一人前、子どもに戻る、若返り、子どもができる。残りの6個も、4個は関係の願い（天敵・モテ・接近・恋人）で、純粋な知的欲求は2つ（魔物・希少種族の研究）しかない。

そして達成方法を見ると、さらに露骨だ。

- 「早くおとなになりたい」の達成条件は `adultBody`。**身体が大人になること。**
- 「子どもに戻りたい」の達成条件は `childBody`。
- 「近づきたい」の達成条件のひとつは `exchangedBody`——**相手の身体になること**で、この願いは叶う。

達成台詞がまた見事だ。

> 「◯◯の身体になって、見えてくるものがあった。**不思議な形で願いが叶った。**」

**この村の住人は、神に願うとき、ほぼ全員が身体のことを願う。** そして神にできる回答も、ほとんどが身体をどうにかすることだ。クロノスの秘薬（15歳以下を16歳に成長させる）、ドライアドの果実（身体をドライアドにする）、松かさの杖、牧神の管笛（6名3組を一括交換）——秘宝ラインナップの中核も同じ方向を向いている。

**邪推: これは、身体を配り直すことでしか人を幸せにできない神の話である。** バッカスは心を癒せない。癒しの奇跡は状態異常と体力を回復し、酒杯の奇跡は酔わせ、狂宴は倫理を削って気分を上げる。悩みそのものに触れる手段はひとつもない。**この神にできるのは、器を取り替えることと、酔わせることだけだ。**

そう読むと、出立の奇跡が「幸福度分の魔素」を返すことの意味も変わってくる。幸せな人間を村から出すと力が戻るということは、**この神は他者の幸福を代謝して生きている**ということだ。神威（=バッカスの復権度）は、村人が巫女や醸造や祈りを務めることで上がっていく（`dictionaryData.js`：巫女で1人+2、醸造で+1、願望達成で+10）。

**つまり構造はこうなっている。** 村人は身体を願う → 神は身体を配り直す → 願望が叶うと神威+10 → 神威が上がると、より大きく身体をいじれる奇跡が解放される。

**これは相互扶助ではなく、閉じた依存の輪だ。** 「意地悪く読むなら」、この村は神を復活させるための培養器であり、願望システムはその培地である。黄金像の建立が「村人たちが望むこと」として発生する（`WORLDVIEW.md`: 「村人たちはバッカスの黄金像建立を望むことがある」）のは、その最終段階だと読める。**村人は自分たちの意志で、村を滅ぼしかねない像を望む。** そしてプレイヤーだけが、それが七つの災厄の引き金だと知っている。

## 9. 弱点と伸びしろ

批評として率直に。改善案を並べて分析を押し流さないよう、4点に絞る。

### (a) 一番の問題は、長さである

`docs/balance/design-goals.md` の目標は、**黄金像初回建立まで中央値9年、許容6～12年**。1年=12ターン、つまり**108ターン、許容範囲の上端で144ターン**。そのうえで黙示録7か月が始まる。

一方、`docs/balance/baseline-results.md` の36か月実測では、標準プレイヤーモデルの3年時点の規模中央値は**60**（観測目安120に対して半分）。目標到達がさらに遠い可能性がある。

**そして前述のとおり、その100ターンの大半は「読むものはあるが、決めることがない」月である。** 賑やかな空白が100回続いた先に、本作で最も作り込まれた部分（黄金像・黙示録・七つの災厄・専用称号）が置かれている。**ほとんどのプレイヤーに届かない**構造になっている疑いは濃い。

作品の癖を消す提案はしたくないので、「テンポを上げろ」「イベントを増やせ」とは言わない。イベントの**数**は足りている。足りていないのは、**プレイヤーに何かを選ばせるイベント**だ。良イベント15種のうち選択肢があるのが「狼の子供」1種だけ、という比率は動かす余地がある。金貨を拾ったなら、使い道を訊けばいい。秘湯を見つけたなら、誰に最初に入らせるか訊けばいい。既存の資産をほぼ使い回したまま、月の手触りが変わる。

そして願望が村で同時1件しか走らない現状の制約が、ここで効いてくる（次項）。

### (b) 願望が村で1件しかない

`village.wish` は単数フィールドで、`tryStartWish` は `getActiveWish(village)` があれば即座に return する。つまり**誰かの願いが走っている12か月間、村の他の誰も神に願えない**。

村人が15人いても、祈りの回線は1本だ。しかも発生率は月20%。

**評価: これは、本作で最も人物が「人物」に見える仕組みが、最も絞られているということだ。** 願望は、村人が神に向かって口をきく唯一の常設チャンネルであり、達成すると神威+10という数値の報酬まで付いている。それが月20%・同時1件・12か月占有では、15人の村でひとりあたり数年に一度しか回ってこない。

前項の「決断が発生しない月」への最も自然な処方は、ここを2～3件の同時進行にすることだと思う。作品の癖を消すどころか、むしろ**願いを配り直す神**という中核を濃くする方向の変更になる。

（技術面では単数フィールドの保存互換が絡むので、実装するなら別途設計が要る。ここでは内容評価としてのみ指摘する。）

### (c) 黙示録の引き返しが軽い

黄金像を破壊すれば黙示録は中断でき、解放フラグは残るので再建できる。第六・第七の敗北時も像が強制破壊されるだけで、村は続く。

**七つの災厄という題材に対して、これはリスクが軽すぎる。** 現状、黙示録は「いつでも降りられるレイド」であり、**公然たる反逆**という `WORLDVIEW.md` の位置づけと噛み合っていない。

ただし、`design-goals.md` が「奇跡と秘宝を使わない全体完走率は0～20%」を目標にしていることを踏まえると、安全弁自体は必要だとも思う。**提案するなら、中断の無料化をやめること**だ。像を自ら引き倒したら、村特性か神威に恒久的でない傷が残る、程度で十分に意味が変わる。神への反逆を取り消した村として。

### (d) 練度がゲームオーバー率に効いていない

`docs/balance/baseline-results.md` の36か月測定:

| モデル | 生存率 | 生存村中の安定率 |
| --- | ---: | ---: |
| 初心者 | 80% | 32.5% |
| 標準 | 78% | 61.5% |
| 熟練者 | **76%** | 73.7% |

**上手いほうが死んでいる。** 文書自身が「これをプレイヤー練度ごとの最終生存率とは扱えない」と正しく留保し、原因を熟練者モデルの未実装部分（危機時の奇跡、勧誘の長期計画、襲撃編成の手動最適化）に求めている。測定基盤側の問題という診断はおそらく正しい。

ただし内容評価として言えば、この数字は**「上手さが生存に反映されるルートが、現状では奇跡と手動戦闘編成にしかない」**ことの傍証でもある。備蓄管理と休養判断（=熟練者モデルv1が実装した範囲）だけでは、生死は変わらない。生死を分けているのは襲撃の当たり外れだ——ゲームオーバー14～33か月の事例のうち、初心者9/10、標準9/11、熟練者8/12が**それ以前に襲撃失敗を含んでいた**。

**評価: 序盤の死因が襲撃に一極集中している。** 資源管理SLGとして、飢餓や冬越し失敗で死ぬケースがもっとあってよいはずで、そこが薄いなら、序盤の食料・資材管理はプレイヤーが思っているほど生死に関わっていない、ということになる。第2章で「警告欄を読む数秒がゲーム画面だ」と書いたが、**その警告の多くは、実は死に直結していない**可能性がある。ここは正式測定で確かめる価値が高い。

## 10. 総評

**Village of Bacchus は、村運営SLGの外形を借りて「身体は交換可能な労働条件である」という一貫した主張を、100ターン以上かけて反復する作品だ。**

その主張は、設定文書の宣言ではなく、実装の隅々に散らばった小さな判断に宿っている。あんまが肉体性別で計算式を分岐すること。勇気が精神側にあって肉体交換で移らないこと。塩の柱が肉体に属していて、着せ替えられること。赤子の口調が意味語を持たないこと。願望13種のうち7種が身体の願いであること。出立の奇跡が幸福度を魔素に換えること。

**弱いのは、その主張が届くまでが遠すぎることだ。** 最も濃い部分（黄金像・黙示録・七つの災厄・専用称号）が、中央値9年=108ターンの先にある。しかもその道中は、出来事の数こそ多いのに、プレイヤーが選ぶ場面がほとんどない。良イベント15種のうち選択肢を出すのは1種だけで、村で同時に走れる祈りは1本だけ。

**強みは、粗さを矯正していないことだ。** 天罰を敵に着せ替えて砕く戦術を、バランス文書は禁止せずに戦術として記録した。倫理を魅力に両替する秘宝を実装した。幸せな村人ほど高く売れる奇跡を、コスト計算式として書いた。これらは「遊びやすさ」の観点からは全部おかしい。だが、**そのおかしさが正確にこの作品の内容そのものである**ため、消せば作品が消える。

批評として最後に一言。この作品にいま必要なのは、システムの追加ではなく、**すでにあるものが見える距離まで前に出ること**だと思う。願望を2件走らせる。既存の良イベントに選択肢を1つ足す。黄金像への道を1～2年縮める。それだけで、この村がどれだけ奇妙な場所だったかが、プレイヤーに届く回数が何倍にもなる。
