# 1年経過（黙示録クリア後）

黙示録クリア後、通常の「次の月へ」の隣に「1年経過」ボタンが解禁される。

- 現在の行動設定を維持して最大12か月を月単位で進める。
- 危篤・飢餓・凍え・絶望が開始時にある場合は実行不可。進行中に発生した場合は、その月の処理を完了して中断する。
- 襲撃は、作戦会議の「自動割り振り」（攻勢）で配置し、迎撃画面と同じ行動順・計算で画面を開かずに戦い切る。勝敗・負傷離脱・失敗時の被害・捕虜・重体判定は通常の襲撃と同じ。回避（要求の支払い）は選ばない。
- 襲撃のあった月は、通常の襲撃と同じく防衛に就いた村人はその月の仕事をしない。
- 自動進行中に出る通知（行動フェーズ結果、季節、祭、願望、建築要望、神威Lv、妊娠・出産など）は、各通知の「閉じる」を押したのと同じ扱いで片付ける。自動進行の終了・中断後に古い通知が残ったり、後から出てきたりしない。
- ランダムイベント「迷い狼」は自動で迎え入れる。
- 訪問者・捕虜の自動勧誘、商人取引、冒険者への新規依頼は行わない。
- 建築要望・願望を能動的に達成しない。通常条件で自然達成した場合のみ達成する。
- 損壊建築は各月開始時に、通常修復費（建設費の50%切り上げ）を払えるものだけ自動修復する。資源不足なら翌月以降へ持ち越す。
- 出産時は村人に命名を任せ、自動進行を止めない。
- 年次レポートには人口・主要資源の増減、襲撃、妊娠/出産、死亡、恋愛関係、願望/要望、迷い狼、雷による肉体交換、自動修復を記録する。
