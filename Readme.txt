1.1. タイトル
Village of Bacchus

1.2. バックストーリー

主人公は豊穣と混沌の神バッカス。
「新しき神」に敗れ、永い眠りについていた彼が目覚めたのは小さな開拓村だった。
既に忘れ去られて久しく、神力もほとんど失われていた彼だったが、豊穣神としての本能と神の力を取り戻すため、
この地にある魔素を利用して奇跡を行使し、村の発展を手助けすることを決意する。

1.3. 序盤の進め方

起動時の画面では、「はじめから」、ローカル保存からの続行、JSON保存からの続行を選べます。
「はじめから」を選ぶと、オープニングが始まります。スキップすればすぐにゲームへ進めます。
オープニングは「保存/読込/説明」の「オープニングを見る」から、いつでも見直せます。
「つづきから（ローカル読込）」には保存した年月と村の規模称号が表示され、保存がない場合は選べません。
オープニングは暗転した画面に声だけが響く演出で、台詞は区切りごとにまとめて表示されます。
画面のクリック（タップ）、Enterキー、スペースキーで読み進められます。
枠の左下にある小さな「>>スキップ」を押せば、いつでもゲーム画面へ進めます。

まず村人の「行動」を設定します。
食料と資材を集めながら、村の発展を目指してください。
食料と資材の初期保管上限は400です。納屋や貯蔵庫で上限を増やせます。

「自動割り振り」を使うと、村の備蓄と村人の適性に応じて行動をまとめて設定できます。
どの資源をどれだけ優先するかは、「保存/読込/説明」の「自動割り振り詳細設定」で調整できます。食料・資材・治安は4段階、資金・技術は3段階で、段階ごとの倍率と区切りを変えられます。手動のチェックを入れた行だけ入力が効き、外すと既定値に戻ります。
各村人の行動欄にあるボタンを「固定」にすると、その村人は自動割り振りの対象から外れます。
村人一覧の見出し右の絞り込みで、肉体性別・精神性別・種族・仕事の選択、特性の自由入力、傷病・恋人あり・既婚のチェックを重ねて表示を絞れます。特性欄は部分一致で探せます。「解除」で戻ります。列の見出しをクリックすると並べ替えできます。名前・肉体・種族は五十音順、行動と役職は選んでいる項目の名前で並びます。
月初には体力・メンタルと勤勉に応じて、行動が一時的に休養または余暇へ切り替わることがあります。

訪問者は種類ごとに体力・メンタル・幸福度の幅が違います。逃れてきた流民や追われた棄民は消耗しており、冒険者や観光客は余裕を持って村へ来ます。

村人や訪問者、捕虜の名前をクリックすると会話画面になります。
村人の話を聞くほか、訪問者の勧誘、捕虜の懐柔・誘惑・解放など、相手の立場に応じた操作を行えます。
冒険者の会話では、資金100・期間6か月の秘宝探索クエストを依頼できます。提示される4候補は同じ訪問中は固定され、成功率はクエストが参照する身体能力1つと精神能力1つ、報酬秘宝ごとの基礎成功率で決まります。依頼した冒険者は結果報告の月初に通常抽選とは別枠で帰還します。

画面下部の用語検索では、行動、建築、奇跡、特性などの詳細を確認できます。

農作業、醸造、漁の実行時には、まれに奇妙な秘宝が見つかることがあります。
行商人は10%の確率で秘宝を持っており、資金300で購入できます。
秘宝「告天使の絵画」は、人型種族・身体性別が女・肉体年齢16歳以上の村人へ使用でき、人型種族であれば年齢上限はありません。翌月に遺伝父不明の子を妊娠し、人間として生まれる子は半神となり、種族を問わず聖霊の加護（知力・勤勉・倫理・勇気+3）を得ます。売却価格は資金200、冒険者クエスト基礎成功率は30%です。
村史では、村の発展や村人の出入り、婚姻、出生、肉体交換などの主要な出来事を確認できます。
村人一覧の記録ボタンから、各人物に関わる出来事を個人記録として確認できます。塩の柱への変化・回復や、村とともに七つの災厄を越えた記録も残ります。襲撃者・訪問者・捕虜一覧では個人記録は開けません。

1.4. 保存と読込

localStorageへのローカル保存と、JSONファイルでの保存・読込に対応しています。
旧バージョンのデータは可能な範囲で互換変換されますが、更新前にはJSONファイルを別途保存しておくことを推奨します。

1.5. 行動の適性

各行動には成果や回復量に関わる適性ステータスがあります。

通常行動の消費は大きく三種類に分かれます。
体力系……体力24、メンタル12を基準に消費
バランス系……体力18、メンタル18を基準に消費
頭脳労働系……体力12、メンタル24を基準に消費

実際の体力消費は主に耐久、メンタル消費は行動ごとの精神ステータスによって軽減されます。

農作業……耐久×勤勉（体力系）
狩猟……筋力×勇気（体力系）
漁……耐久×勇気（体力系）
伐採……筋力×勤勉（体力系）
採集……器用×知力（バランス系）
内職……器用×勤勉（頭脳労働系）
行商・丁稚……魅力×知力（バランス系）
研究・研究助手……知力×魔力（頭脳労働系）
警備……筋力×倫理（体力系）
看護……魔力×倫理（バランス系）
詩人……魅力×知力（バランス系）
踊り子……魅力×好色（バランス系）
神官・シスター……魅力×倫理（頭脳労働系）
あんま（男性肉体）……筋力×知力（バランス系）
あんま（女性肉体）……魅力×好色（バランス系）
写本……耐久×知力（頭脳労働系）
錬金術……魔力×知力（バランス系）
機織り……器用×勤勉（バランス系）
醸造……魔力×耐久×勤勉（バランス系）
巫女……魅力×魔力×好色（バランス系）
バニー……魅力×好色（バランス系）

子供向けの「遊び」「お手伝い」、固定行動の「揺籃」「療養」「臨終」「塩柱」などは、上記の通常行動とは別の処理を行います。
子供向けの行動段階は精神年齢の数値ではなく、無垢・萌芽・思春期・未成熟の精神特性で決まります。
未成熟の間は遊び・休養だけが可能で、負傷・疫病などの時は療養が優先されます。
療養は体力とメンタルを回復し、負傷を解除します。疫病は療養では解除されず、月末の状態異常一括解除で回復します。負傷は月末処理では解除されません。
身体特性「繊細な指」は、内職、機織り、あんま（男）、あんま（女）の効果を1.2倍にします。
精神特性「酒豪」は耐久20以上・好色18以上の村人が10%で獲得します。酒杯、宴会、狂宴の奇跡による体力・メンタル・幸福度の回復量が1.5倍になり、酒豪の村人には宴会または狂宴で達成できる願望「パーッと騒ぎたい」が発生することがあります。
疫病患者がいる月末には、患者数×2人を上限として非罹患者へ感染予約が付くことがあり、翌月初に発症します。
醸造所建設後に解放される清拭の奇跡は、魔素60で3か月間「清浄」を付与し、疫病の感染と重体の危篤化を防ぎます。

1.6. 襲撃戦

迎撃……前衛。籠城と合わせた前衛枠は初期6人で、有効な木柵と環濠により各+1されます。
　　　　物理ダメージ = floor((筋力×勇気÷400)×50 - 相手の耐久)
　　　　魔法ダメージ = floor((魔力×勇気÷400)×25)
　　　　物理と魔法のうち高い方を自動で使用します。

籠城……前衛。有効な木柵で解放されます。攻撃はせず、受けるダメージが0.8倍になります。
　　　　有効な環濠がある場合は0.7倍になります。近接攻撃を受けた時は、通常攻撃の半分の威力で反撃します。

射撃……中衛。有効な櫓で解放されます。中衛枠は有効な櫓1基につき1人で、火砲と共有します。
　　　　櫓の設置上限は村の発展段階に応じて増え、最大4人です。
　　　　ダメージ = floor((器用×勇気÷400)×40 - 相手の耐久×1.5)
　　　　反撃を受けませんが、中衛が受けるダメージは1.2倍です。

火砲……中衛。有効な魔導工廠で解放されます。中衛枠は射撃と共有します。
　　　　精神特性「文明忌避」「不殺」を持つ村人は選べません。
　　　　ダメージ = floor((魔力×知力÷400)×20)
　　　　ターンの最後に攻撃し、火砲同士では勇気の高い順に行動します。
　　　　反撃を受けませんが、受けるダメージは1.5倍です。

罠作成……後衛。参加上限は3人です。
　　　　　0ターン目に「floor((器用×知力÷400)×30)」のダメージを与えて離脱します。

襲撃中は、村情報の上部に赤字の「作戦会議」ボタンが出ます。ここで前衛（迎撃・籠城）、中衛（射撃・火砲）、後衛（罠作成）をチェックで割り振り、予想ダメージと被弾のしやすさを見比べてから「迎撃開始」で防衛フェーズへ進みます。就けない行動や枠が埋まった戦列は灰色になります。
襲撃者が赤子、幼狼、危篤、重体の場合は行動不能かつ被ダメージ3倍、疫病、負傷、過労、産褥の場合は行動不能かつ被ダメージ2倍です。

襲撃予約……1195年6月までは予約されません。
　　　　　　月初判定で当選しても当月には発生せず、翌月の襲撃として予約されます。
　　　　　　襲撃後の翌月は予約判定がなく、2か月目以降は10%から毎月1.8倍、通常最大75%まで上昇します。
　　　　　　荒廃中は襲撃予約確率が2倍になり、最大100%になります。
　　　　　　太陽の巫女がいる場合は60%、趣味「占い」「天体観測」の村人がいる場合はそれぞれ30%で、予約済み襲撃を事前通知します。

豊かな村以降は、ゴブリンリーダー1体、ゴブリン射手2〜3体、通常ゴブリン2〜3体で構成されるゴブリン軍団が出現します。
ゴブリンリーダーは戦闘開始時に「弱者狙い」を発動し、80%で攻撃可能な村人のうち体力が最も低い者を狙います。
自治集落では、ゴブリンリーダー1体、ゴブリン射手2体、キュクロプス1体、ハーピーの長1体、餓狼2体で構成されるモンスター・スタンビードが出現します。
傭兵団には30%で傭兵射手1名が加わります。

1.7. 捕虜と迎撃失敗

営倉または牢獄建設後に襲撃者を全滅させると、50%で捕縛可能な襲撃者1名を捕虜にできます。
捕虜は営倉のみなら最大1名、牢獄建設後は最大3名までで、行動は「虜囚」に固定されます。
村人上限には数えませんが、食料と冬の資材を消費し、飢餓や凍えは村人に準じて受けます。
虜囚では月末に体力+10、メンタル+10を得ます。
捕虜は6か月後に自動解放され、会話画面で解放期限を確認できます。
捕虜は会話から懐柔・誘惑・解放でき、交換の奇跡と交換の奇跡・強の対象にもなります。
懐柔・誘惑の成功率係数は、捕虜になる前の襲撃者の種類によって変わります。
精神特性「狂信」を持つ捕虜への懐柔・誘惑成功率は0%です。
捕虜として収容した時点で、精神特性「餓狼」「首長」「秘蹟：剣」「秘蹟：盾」「秘蹟：光」は失われます。
癒しの奇跡と酒杯の奇跡も捕虜を対象にできます。

迎撃失敗時の基本被害は治安-10、村人幸福度-30で、村人体力は低下しません。資源・建物への被害と重体判定は襲撃ごとに異なります。
建物被害を持つ襲撃で敗北した場合だけ、有効な建築物が1件ランダムに損壊します。バッカスの黄金像は襲撃敗北やランダムイベントによる通常の損壊対象にはなりません。損壊中の建築物は効果を発揮せず、建築画面から修繕できます。
一部の高危険度襲撃では、襲撃終了時に体力0の村人1名へ重体判定が発生します。

1.8. 交換の奇跡と黙示録

交換の奇跡は村人・捕虜から2名、交換の奇跡・強は村人・捕虜・訪問者・襲撃者から2名を選び、肉体を交換します。
塩の柱状態の人物も、両方の交換の奇跡、松かさの杖、牧神の管笛、ドライアドの果実、落雷による肉体交換の対象になります。塩の柱と自然回復までの残り期間は肉体に属し、肉体交換では相手へ移ります。ドライアドの果実を使った場合はドライアドの身体へ変わるため、対象者の塩の柱は解除されます。
黙示録の四騎士だけは交換の奇跡と交換の奇跡・強が無効です。同行する聖征軍や翼人兵は交換できます。
バッカスの黄金像が有効な間は、交換の奇跡と交換の奇跡・強の消費魔素が4分の1になります。

黄金像を建築すると黙示録が始まり、次月から「血の川」「天を覆う蝗」「硫黄」「疫病」「塩の柱」「聖征軍と戦争」「上位翼人兵と支配」の七災厄が順に発生します。
第四の災厄ではランダムな村人最大3名が疫病になり、第七の災厄は7ターン防衛すると部分成功になります。
第二の災厄では食料の60%を失い、3か月経過または黙示録が解除されるまで村特性「飛蝗」が付与されます。飛蝗の間は農作業、採集、伐採、醸造の成果が0.2倍になります。
黙示録中は通常のランダムイベントと通常襲撃が停止します。黄金像を破壊すると黙示録を中断でき、第六・第七災厄の襲撃に敗北した場合も黄金像が破壊されます。
秘宝「伝令神の手形」は、黙示録の第六・第七の災厄では使用できません。
第六の災厄は重装兵2名、聖女1名、聖騎士1名、上位翼人1名、《戦争》1名の6名で編成され、上位翼人には聖女の輝きが付与されません。
第七の災厄は翼人兵3名、秘蹟：盾・秘蹟：剣・秘蹟：光をそれぞれ持つ上位翼人3名、《支配》1名の7名で編成され、翼人兵と上位翼人には聖女の輝きが付与されません。
《支配》は第七の災厄の1ターン目に倫理が最も低い前衛・中衛参加者、3ターン目に好色が最も高い前衛・中衛参加者、5ターン目に幸福度が最も高い前衛・中衛参加者へ裁きの光で固定200ダメージを与えます。身体特性「光輪」があれば裁きの光を無効化します。
黙示録クリア後の騒擾の奇跡では、通常6種と異端2種から規模別襲撃テーブルを選び、その中から襲撃を抽選できます。
第五の災厄では勇気が高い側の村人から最大3名が塩の柱になります。塩の柱は付与後3か月、または七つの災厄を越えると解除されます。癒しの奇跡では治療できません。
塩の柱の間は行動が「塩柱」に固定され、会話・通常イベントなどの対象外となり、食料・冬の資材を消費せず、体力・メンタル・幸福度も変動しません。
肉体交換で襲撃者へ移った塩の柱が戦闘中に1以上のダメージを受けると、砕け散った旨が表示され、体力が0になります。
七つの災厄を越えると異端と塩の柱が解除され、村人は専用称号「七災を越えし者」を獲得し、神威Lv6の奇跡が解放されます。
