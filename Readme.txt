1.1. タイトル
Village of Bacchus

1.2. バックストーリー

主人公は豊穣と混沌の神バッカス。
「新しき神」に敗れ、永い眠りについていた彼が目覚めたのは小さな開拓村だった。
既に忘れ去られて久しく、神力もほとんど失われていた彼だったが、豊穣神としての本能と神の力を取り戻すため、
この地にある魔素を利用して奇跡を行使し、村の発展を手助けすることを決意する。

1.3. 序盤の進め方

まず村人の「行動」を設定します。
食料と資材を集めながら、村の発展を目指してください。
食料と資材の初期保管上限は400です。納屋や貯蔵庫で上限を増やせます。

「自動割り振り」を使うと、村の備蓄と村人の適性に応じて行動をまとめて設定できます。
各村人の行動欄にあるボタンを「固定」にすると、その村人は自動割り振りの対象から外れます。
月初には体力・メンタルと勤勉に応じて、行動が一時的に休養または余暇へ切り替わることがあります。

村人や訪問者、捕虜の名前をクリックすると会話画面になります。
村人の話を聞くほか、訪問者の勧誘、捕虜の懐柔・誘惑・解放など、相手の立場に応じた操作を行えます。

画面下部の用語検索では、行動、建築、奇跡、特性などの詳細を確認できます。

農作業、醸造、漁の実行時には、まれに奇妙な秘宝が見つかることがあります。
行商人が秘宝を持っている場合は、資金300で購入できます。
村史では、村の発展や村人の出入り、婚姻、出生、肉体交換などの主要な出来事を確認できます。
村人一覧の記録ボタンから、各人物に関わる出来事を個人記録として確認できます。襲撃者・訪問者・捕虜一覧では個人記録は開けません。

1.4. 保存と読込

localStorageへのローカル保存と、JSONファイルでの保存・読込に対応しています。
旧バージョンのデータは可能な範囲で互換変換されますが、更新前にはJSONファイルを別途保存しておくことを推奨します。

1.5. 行動の適性

各行動には成果や回復量に関わる適性ステータスがあります。

通常行動の消費は大きく三種類に分かれます。
体力系……体力24、メンタル12を基準に消費
バランス系……体力18、メンタル18を基準に消費
頭脳労働系……体力12、メンタル24を基準に消費

実際の体力消費は主に耐久、メンタル消費は行動ごとの精神ステータスによって軽減されます。

農作業……耐久×勤勉（体力系）
狩猟……筋力×勇気（体力系）
漁……耐久×勇気（体力系）
伐採……筋力×勤勉（体力系）
採集……器用×知力（バランス系）
内職……器用×勤勉（頭脳労働系）
行商・丁稚……魅力×知力（バランス系）
研究・研究助手……知力×魔力（頭脳労働系）
警備……筋力×倫理（体力系）
看護……魔力×倫理（バランス系）
詩人……魅力×知力（バランス系）
踊り子……魅力×好色（バランス系）
神官・シスター……魅力×倫理（頭脳労働系）
あんま（男性肉体）……筋力×知力（バランス系）
あんま（女性肉体）……魅力×好色（バランス系）
写本……耐久×知力（頭脳労働系）
錬金術……魔力×知力（バランス系）
機織り……器用×勤勉（バランス系）
醸造……魔力×耐久×勤勉（バランス系）
巫女……魅力×魔力×好色（バランス系）
バニー……魅力×好色（バランス系）

子供向けの「遊び」「お手伝い」、固定行動の「揺籃」「療養」「臨終」「塩柱」などは、上記の通常行動とは別の処理を行います。

1.6. 襲撃戦

迎撃……前衛。籠城と合わせた前衛枠は初期6人で、有効な木柵と環濠により各+1されます。
　　　　物理ダメージ = floor((筋力×勇気÷400)×50 - 相手の耐久)
　　　　魔法ダメージ = floor((魔力×勇気÷400)×25)
　　　　物理と魔法のうち高い方を自動で使用します。

籠城……前衛。有効な木柵で解放されます。攻撃はせず、受けるダメージが0.8倍になります。
　　　　有効な環濠がある場合は0.7倍になります。近接攻撃を受けた時は、通常攻撃の半分の威力で反撃します。

射撃……中衛。有効な櫓で解放され、有効な櫓1基につき1人が参加できます。
　　　　櫓の設置上限は村の発展段階に応じて増え、最大4人です。
　　　　ダメージ = floor((器用×勇気÷400)×40 - 相手の耐久×1.5)
　　　　反撃を受けませんが、中衛が受けるダメージは1.2倍です。

罠作成……後衛。参加上限は3人です。
　　　　　0ターン目に「floor((器用×知力÷400)×30)」のダメージを与えて離脱します。

襲撃予約……1195年6月までは予約されません。
　　　　　　月初判定で当選しても当月には発生せず、翌月の襲撃として内部予約されます。
　　　　　　襲撃後の翌月は予約判定がなく、2か月目以降は10%から毎月1.8倍、通常最大75%まで上昇します。
　　　　　　荒廃中は襲撃予約確率が2倍になり、最大100%になります。
　　　　　　太陽の巫女がいる場合は60%、趣味「占い」「天体観測」の村人がいる場合はそれぞれ30%で、予約済み襲撃を事前通知します。

1.7. 捕虜と迎撃失敗

営倉または牢獄建設後に襲撃者を全滅させると、50%で捕縛可能な襲撃者1名を捕虜にできます。
捕虜は営倉のみなら最大1名、牢獄建設後は最大3名までで、行動は「虜囚」に固定されます。
村人上限には数えませんが、食料と冬の資材を消費し、飢餓や凍えは村人に準じて受けます。
虜囚では月末に体力+10、メンタル+10を得ます。
捕虜は6か月後に自動解放され、会話画面で解放期限を確認できます。
捕虜は会話から懐柔・誘惑・解放でき、交換の奇跡と交換の奇跡・強の対象にもなります。

迎撃失敗時の資源・治安・体力・幸福度への被害は襲撃ごとに異なります。
建物被害を持つ襲撃で敗北した場合だけ、有効な建築物が1件ランダムに損壊します。損壊中の建築物は効果を発揮せず、建築画面から修繕できます。
一部の高危険度襲撃では、襲撃終了時に体力0の村人1名へ重体判定が発生します。

1.8. 交換の奇跡と黙示録

交換の奇跡は村人・捕虜から2名、交換の奇跡・強は村人・捕虜・訪問者・襲撃者から2名を選び、肉体を交換します。
塩の柱状態の村人も両方の交換の奇跡で対象にできます。塩の柱と自然回復までの残り期間は肉体に属し、交換相手へ移ります。
黙示録の四騎士だけは交換の奇跡と交換の奇跡・強が無効です。同行する聖征軍や翼人兵は交換できます。
バッカスの黄金像が有効な間は、交換の奇跡と交換の奇跡・強の消費魔素が半分になります。

黄金像を建築すると黙示録が始まり、次月から「血の川」「天を覆う蝗」「硫黄」「疫病」「塩の柱」「大規模聖征軍と戦争」「上位翼人兵と支配」の七災厄が順に発生します。
黙示録中は通常のランダムイベントと通常襲撃が停止します。黄金像を破壊すると黙示録を中断でき、第六・第七災厄の襲撃に敗北した場合も黄金像が破壊されます。
塩の柱は付与後3か月、または四騎士の災厄を越えると解除されます。癒しの奇跡では治療できません。
塩の柱の間は行動が「塩柱」に固定され、会話・通常イベントなどの対象外となり、食料・冬の資材を消費せず、体力・メンタル・幸福度も変動しません。
四騎士の災厄を越えると仮エンディングとなり、異端と塩の柱が解除され、神威Lv6の奇跡が解放されます。
