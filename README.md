1.1 仮タイトル<br>
Village of Bacchus（仮）

1.2. バックストーリー
主人公は豊穣と混沌の神バッカス。<br>
「新しき神」に敗れ、永い眠りについていた彼が目覚めたのは 小さな開拓村だった。<br>
既に忘れ去られて久しく、神力も殆ど失われていた彼だったが<br>
豊穣心としての本能と神の力を取り戻すため、<br>
この地にある魔素を利用して奇跡を行使し、村の発展を手助けすることを決意する。<br>

1.3. 序盤の進め方<br>
起動時の画面では、「はじめから」、ローカル保存からの続行、JSON保存からの続行を選べます。<br>
「はじめから」では、オープニングを見るか選んでからゲームを開始します。<br>
オープニングは暗転した画面に声が響く演出です。画面をクリック（タップ）するかEnter・スペースキーで読み進められます。文字送りの途中で操作すると、その台詞をすぐに全部表示します。右上の「スキップ」でいつでも飛ばせます。<br>
まず村人の「行動」を設定します。<br>
食料と資材を集めながら、村の発展を目指してください。<br>
食料と資材には保管上限があり、初期上限は400です。納屋や貯蔵庫で上限を増やせます。<br>
村人は基本的に「行動」で設定した内容を実行しますが、<br>
プレイヤーが別の「行動」を指示することも可能です。<br>
村人は体力やメンタルが減少すると自動で休養します。<br>
勤勉が高い村人ほどギリギリまで頑張る傾向にあります。<br>

名前をクリックすると会話画面になります。<br>
村人の話を聞いたり、行動の任命や訪問者の勧誘を行うことができます。冒険者には、資金100・期間6か月の秘宝探索クエストも依頼できます。<br>

右下のボックスにて、行動や用語の詳細を検索することが可能です。<br>
画面右上の「スマホ仮」モードは、スマホ横向きでの利用を想定した表示です。<br>

農作業、醸造、漁の最中に、まれに奇妙な秘宝が見つかることがあります。<br>
行商人は10%の確率で秘宝を持っており、資金300で購入できます。<br>
秘宝「告天使の絵画」は条件を満たす肉体女性へ使用でき、翌月に遺伝父不明の神秘的な妊娠をもたらします。人間として生まれる子は半神となり、聖霊の加護を得ます。<br>
村史では、村の発展や村人の出入り、婚姻、出生、肉体交換などの主要な出来事を確認できます。<br>
村人一覧の記録ボタンから、各人物に関わる出来事を個人記録として確認できます。塩の柱への変化・回復や、村とともに七つの災厄を越えた記録も残ります。襲撃者・訪問者・捕虜一覧では個人記録は開けません。<br>

1.4. その他<br>
ローカル保存とjsonでの保存ができますが、<br>
バージョンアップに伴いセーブファイルが使えなくなる可能性があります。
